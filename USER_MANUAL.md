# MMFC Library System — Simple User Guide

**Mindanao Medical Foundation College Library**  
*(Powered by Pantas)*

This guide explains how to use the library system in plain language. You do not need to be a computer expert — just follow the steps that match who you are.

---

## What is this system?

This is the college library’s online system. It helps people:

- Apply for a **library ID**
- **Enter and leave** the library by scanning a card or code
- **Look up books** and online materials
- Let library staff **approve applications**, **print IDs**, and **manage books**

Think of it as the library’s digital front desk and attendance desk in one place.

# Part 1: For Students and Employees

## A. How to apply for a library ID (no login needed)

Anyone can apply online. Library staff will review your application before your ID is ready.

### Step 1 — Open the registration page

1. Open the library website.
2. You should see a **Login** page that says something like **“Welcome! Let’s Begin”**.
3. Click **Register**.

*(Or ask the library for the registration link.)*

### Step 2 — Choose Student or Employee

At the top you will see two tabs:

- **Student** — for students  
- **Employee** — for faculty / staff / employees  

Click the one that matches you.

### Step 3 — Fill in your details

**If you are a Student**, you will usually need:

- First name and last name  
- Student ID (if you have one)  
- Birth date  
- Blood type  
- Course and year level (1st–5th year)  
- Emergency contact (name, relationship, phone, address)  
- A **1×1 ID photo** (plain white background works best)  
- Your **signature** (draw it on the screen; you can clear and try again)

When finished, click **Submit Student Registration**.

**If you are an Employee**, you will usually need:

- Name, department, position  
- Full-time or part-time  
- Employee ID, birth date, sex, blood type, civil status  
- Government ID numbers (TIN, PhilHealth, SSS, Pag-IBIG) — numbers only  
- Emergency contact and address  
- A **formal picture**  
- Your **signature**

When finished, click **Submit Employee Registration**.

### Step 4 — Wait for approval

Your application does **not** create an ID right away. Library staff must:

1. Review it  
2. **Approve** it (or reject it if something is wrong)  

After approval, the library can print your ID. Ask the library when you can pick it up.

---

## B. Common words you will see

| Word you see | What it means |
|--------------|----------------|
| **Patron** | A person registered with the library (student or employee) |
| **Pending** | Your application is waiting for staff to review it |
| **Approve / Reject** | Staff accepts or declines an application |
| **QR Code / RFID** | The code or chip on your ID used for scanning |
| **IN / OUT** | You entered or left the library |
| **Check Out / Check In** | Borrowing a book or returning a book |
| **OPAC / Library Landing** | The simple book-browsing page for students and faculty |

---

## C. Using the Attendance scanner at the library

The attendance page is like a kiosk. You usually do **not** need to log in.

1. Go to the **Attendance** screen (or use the computer/tablet set up at the library).
2. Wait until it says **“Ready to scan”**.
3. Scan your library ID (QR code or RFID tag) when prompted.
4. The screen will show your name and whether you are **IN** or **OUT**.
   - First scan of a visit → usually **IN**  
   - Scan again when leaving → usually **OUT**

**Tips**

- Hold the card steady until you hear/see a response.  
- If you see **“RFID not recognized”**, your ID may not be registered yet — ask the library staff.  
- Books can also be scanned here to check if they are borrowed or not.

---

## D. Browsing books online (students / faculty with a login)

If the library gave you an account:

1. Go to the **Login** page.
2. Enter your **Email** and **Password**.
3. Click **Login**.
4. You will land on the **Library Landing** page.

From there you can:

- Look at **New Arrival Books**
- Search by typing a book title
- Filter by course, year, or type of material
- Click a book to see details (title, author, call number, available or borrowed)
- Open **E-Book** / e-resources for online materials
- Click **Logout** when you are done

# Part 2: For Library Staff and Admins

This section is for people who work in the library.

After you log in as **staff** or **admin**, you will usually see the **Home** (Book Kiosk) page. The main menu often includes:

- **Home**
- **Attendance**
- **Attendance Logs** *(mostly for admins)*
- **ID Generation**
- **Logout**

Other tools (cataloging, prospectus, files, user accounts) may appear on deeper pages or for admins.

---

## A. Logging in

1. Open the library website → **Login**.
2. Enter your staff/admin **Email** and **Password**.
3. Click **Login**.
4. You should arrive at **Home**.

If you see **“Invalid credentials”**, check your email/password.  
If you see **“Unauthorized role”**, ask an admin to fix your account role.

When finished for the day, click **Logout**.

---

## B. Approving student or employee applications

People register online and wait in a queue. You approve them here.

1. Click **ID Generation**.
2. Click **Pending Registrations**.
3. Choose:
   - **View Students**, or  
   - **View Employees**
4. Open an application and review the details and photo.
5. Click **Approve** if everything looks correct, or **Reject** if it does not.

**What Approve does:** creates the library record and prepares a QR code so the person can get an ID and use attendance.

---

## C. Finding people and printing IDs

1. Go to **ID Generation**.
2. Use the tabs:
   - **Students**
   - **Faculty** (employees)
3. Use **Search** if you need to find someone quickly.
4. On the person’s row, click **Generate**, then choose:
   - **Front** — front of the ID  
   - **Back** — back of the ID  
   - **Download ZIP** — both sides together  

You can also **Edit** or delete a record from the row **Options** (be careful with delete).

### Adding a person yourself (admin)

Admins can skip the pending queue:

1. On **ID Generation**, click **+ Register Patron**.
2. Fill in the form.
3. Click **Register Patron**.
4. Generate the ID as above.

---

## D. Running the Attendance kiosk

1. From the menu, open **Attendance**.
2. Leave this page open on the kiosk computer.
3. Ask patrons to scan their ID when entering or leaving.
4. The side panel shows the person’s name and **IN** / **OUT**.

Use **Home** to return to the main staff page.

---

## E. Viewing and exporting Attendance Logs (admin)

Use this when you need a record of who came in and out.

1. Open **Attendance Logs**.
2. Set filters if needed:
   - **From** / **To** dates  
   - Student name  
   - Course  
   - Year level  
3. Click **Search**.
4. Review the list (name, course, IN/OUT, time scanned).
5. Click **Export PDF** or **Export Excel** if you need a file to print or share.

---

## F. Recording book borrowing and returns (admin)

This is separate from door attendance. It records when a book is borrowed or returned.

1. Open **Logs** → **Book Check-In & Check-Out Kiosk** (wording may vary slightly).
2. Enter:
   - **RFID Tag** of the book  
   - **Patron’s Name**  
   - **Action**: **Check Out** (borrow) or **Check In** (return)
3. Click **Record Transaction**.
4. You can download a **Transactions Report** when needed.

---

## G. Adding and managing books (staff / admin)

1. Open the book catalog / cataloging area (**Cataloging** or **Add New Book**).
2. Fill in the book details (title, author, ISBN, call number, RFID, cover photo, and other library fields).
3. Save the book.
4. Later you can **View**, **Edit**, or **Delete** a book from the list.
5. You may also:
   - Filter by **All** / **Available** / **Borrowed**
   - **Import Books** from a spreadsheet
   - **Export Books**
   - Open **View E-Resources** for online materials

*(Some of these buttons appear mainly on admin/catalog pages rather than the simple Home menu.)*

---

## H. Managing e-resources (online materials)

1. Open **E-Resources Collection**.
2. Click **Add New E-Resource**.
3. Enter title, author, year, publisher, source, type (Journal, Newspaper, E-book, Magazine, Periodical), link, and program/course if asked.
4. Save.
5. Later use **Edit**, **Delete**, or **View** (opens the link).

---

## I. Programs and courses — Prospectus Manager (admin)

Use this to keep the list of programs and subjects up to date (used when registering students and organizing books).

1. Open **Prospectus Manager**.
2. **Add Program/Strand** (code, name, years).
3. Expand a program to add **subjects** (subject code and name).
4. Edit or delete programs/subjects when they change.

---

## J. File Repository (admin)

A simple place to store and share library files.

1. Open **Repository** / **Admin File Manager**.
2. Optionally type a **Folder Name**.
3. Choose a file → **Upload File**.
4. View, download, or delete files as needed.

---

## K. Creating login accounts (admin)

This creates people who can **log in** to the system (different from printing a library ID).

1. Open **Create Account** or **User Accounts**.
2. Create a user with a role such as:
   - **Student**
   - **Staff**
   - **Faculty**
3. Edit or remove accounts when someone’s access should change.

# Troubleshooting (simple fixes)

| Problem | What to try |
|---------|-------------|
| I cannot log in | Check email and password carefully. Caps Lock off. Ask staff to reset/create your account. |
| “RFID not recognized” | Your ID may not be approved yet, or the tag is wrong. Ask library staff. |
| I submitted registration but have no ID | Wait for staff approval, then ask when IDs will be printed. |
| Photo/signature will not upload | Use a clear photo; try a smaller file; redraw the signature. |
| Page looks blank or stuck | Refresh the page. If it still fails, tell staff which button you clicked. |
| I clicked the wrong Approve/Reject | Tell an admin right away so they can correct the record. |

---

# Tips for less tech-savvy users

1. **Read the button labels** — the system usually tells you what will happen (**Submit**, **Approve**, **Generate**, **Export**).
2. **Do one step at a time** — finish a form before opening other tabs.
3. **Save or submit before leaving** — if you close the page early, your form may be lost.
4. **Ask the library** if you are unsure — especially before deleting anything.
5. **Always log out** on a shared computer when you are done.
